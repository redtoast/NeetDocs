# Event API

Source: `_G.event`

## Summary

The event API allows computers to receive spontaneous information, and is divided into 6 categories.

The categories are as follows:
- Unlabeled: This queue should remain empty, but it does exist for any unlabeled events.
- User: Events generated by or obviously relating to the user(s).
- System: For events relating to the inherent computer.
- Network: For all kinds of network communication local or internet based.
- Peripheral: Events from, or about peripherals.
- Compatibility: Events generated from CC:Tweaked peripherals, or hypothetically other foreign event sources.

Note, the event api is very centralized, and multiple programs completely for access to the event queue will almost certainly lead to events going missing or being taken by the wrong process, if your making a complex system its most likely worth your time to devise a process dedicated to distributing events.

Events are also represented by a list of primitive values, always starting with an identifying string, these docs will represent an event [String, Any...] as just an 'Event.'

## Functions

### queueEvent(Category, event, args...)
Manually appends a new event to the chosen queue, can be used just for normal event purposes or to add make events pulled from the queue.

### getQueue(Category, filter = nil)
Retrieves the entire contents on a queue, or all events with the given filter. Events pulled by this function are removed from the queue.

`returns: Event[]`

### getFirst(Category, filter = nil)
Gets the first event from the given queue that matches the filter, if there is no filter it will just pull the first event.

```
while true do
    --try to pull a new keyboard event.
    local event = event.getFirst("user", "keyPressed")
    if event then
        --events are lists remember, so event is a list.
        --a keyPressed event has its identifier "keyPressed", then a keycode, letter, and key modifiers.
        if (event[3] ~= "") print(event[3]) --we can print the letter, if the keypress was for a letter key.
    else
        chip.sleep(10)
    end
end
```

`returns: Event | Nil`

### clear(Category)
Clears the given event queue.

### clear()
Clears ALL events in all queues.
